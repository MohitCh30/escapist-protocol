# Escape Protocol: Daily Lockdown

A daily stealth-runner built for Reddit's **Game of the Day Hackathon 2026**. Ported and significantly expanded from *Escape Protocol: Class Zero* — a narrative choice game originally built for an internship task; the core morality cast carries over, the gameplay, daily loop, and Reddit-native systems are entirely new.

## The game

An AI system has locked down a school. Classmates are trapped. You run each sector, dodge drone light-cones, and decide their fates — rescue, abandon, or sacrifice. Every choice moves the score board (morality) and, more importantly, moves the clock: **heroism literally costs seconds**. Being cold-hearted doesn't mean you lose to time, it means you trade people for it.

**One seeded day shared by everyone on the subreddit.** Same sectors. Same NPCs. Same sweep patterns. Daily leaderboard by fastest escape time, tie-broken by number of lives saved.

## Features

- **Daily seeded sectors** (auto-generated by date-seed → deterministic for everyone today, different tomorrow)
- **Stealth loop** — manual run, freeze = hidden (SQUID_GAME-style detection), jump barriers/gaps, light-cone warning fill meter
- **Morality economy** — rescue +3s / abandon +1s / sacrifice +0s, plus sector-modifiers: carrying an injured classmate = −10% speed, +40% alert peril; betraying them = +8% speed, −20% peril
- **Wound/Subjugation** — alerts accumulate; two alarms in one sector = sector reset +10s
- **Streaks**, rank on the daily board, aggregate NPC survival stats for the subreddit
- **Share-to-comments** — one click posts your result card to the post's comment thread
- **Live TODAY panel** on the ending screen: players today, your rank, streak, per-NPC rescue rate

## Controls

- **MOVE**: hold `→` or `D` / hold right 35% of screen
- **JUMP**: `SPACE`, `↑`, or `W` / tap middle 35%
- **HIDE**: hold `↓`, `S`, or `SHIFT` / hold left 30% (or just stop moving)

## Stack

- Devvit Web (Interactive Post) — [`@devvit/web`](https://developers.reddit.com/)
- Phaser 3.81 + Vite + TypeScript — gameplay client
- Hono serverless API + Redis — daily seed, leaderboards, streaks, aggregates, comments
- Art: 100% runtime-generated pixel-and-shape sprites (no external art downloads) + one AI-sourced background image bundled from the original project

## Development

```bash
npm install
npm run dev        # devvit playtest (needs devvit login + a mod subreddit)
npm run build
npm run test:unit  # bot plays every day 60 days out × hero/ruthless, asserts completability
```

### The bot test

`tests/sim.test.ts` is a scripted-bot physics simulation of the actual level + controller code. It runs **60 days × 2 moral strategies × 4 sectors** and asserts that *every* seeded day is completable without falling into a gap. This is how the difficulty curve gets tuned — no "played it on my machine" fixes.
